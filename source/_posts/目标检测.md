### Loss合辑

#### Focal loss
用于处理目标检测中正负样本比例失衡的问题。【一张图像可以有成千上万个候选框，但是只有很少的一部分包含目标】【**也可以处理long-tail问题**】

以二分类为例：

$$

\begin{equation}
    CE=-ylogy'-(1-y)log(1-y')=
    \begin{cases}
        -logy', & \text{y=1}\\
        -log(1-y'), & \text{y=0}
    \end{cases}
\end{equation}

$$

 其中，$y'\in$ (0,1)表示输出类别对应的概率。

通常会在交叉熵的前面加一个参数$\alpha$控制正负样本对loss的贡献，即

$$

\begin{equation}

    CE=
    \begin{cases}
        -\alpha logy', & \text{y=1}\\
        -(1-\alpha )log(1-y'), & \text{y=0}
    \end{cases}
\end{equation}

$$

此外，【当某类样本的概率越大，也就也意味着更容易被识别为该样本】。改进式 ([\[平衡正负样本\]](#平衡正负样本))：

$$

\begin{equation}
    FL=
    \begin{cases}
        -\alpha (1-y')^\gamma logy', & \text{y=1}\\
        -(1-\alpha )y'^\gamma log(1-y'), & \text{y=0}
    \end{cases}
\end{equation}

$$

<img src="/images/target_detection/focalloss.jpg" style="max-width:100%;height:auto;display:block;margin:0 auto;" />
<figcaption>正样本概率</figcaption>
</figure>

由图[1](#focalloss)不难发现【仔细看图】：$y'$越大，$FL$越小，它对总体的$FL$的贡献就越小。【此时标签为1】【**降低高置信度样本的损失**，通俗地讲就是，容易被识别的类别就只要求预测概率超过0.5就可以了，不用过度追求预测概率为1，应该更加关注难以分类的样本】

```python
def forward(self, pred, true):
        loss = self.loss_fcn(pred, true)
        pred_prob = torch.sigmoid(pred)  # prob from logits
        p_t = true * pred_prob + (1 - true) * (1 - pred_prob)
        alpha_factor = true * self.alpha + (1 - true) * (1 - self.alpha)
        modulating_factor = (1.0 - p_t) ** self.gamma
        loss *= alpha_factor * modulating_factor
        if self.reduction == 'mean': return loss.mean()
        elif self.reduction == 'sum': return loss.sum()
        else: return loss
```

#### Distribution Focal Loss
$$

\begin{equation}
    \mathbf{DFL}\left(S_i, S_{i+1}\right) = -\left(\left(y_{i+1} - y\right)\log\left(S_i\right) + \left(y - y_i\right)\log\left(S_{i+1}\right)\right)
\end{equation}

$$

 其中，$S_i = \frac{y_{i+1} - y}{y_{i+1} - y_i}$，$S_{i+1} = \frac{y - y_i}{y_{i+1} - y_i}$，$\hat{y} = \sum_{j=0}^nP\left(y_j\right)y_j = S_iy_i + S_{i+1}y_{i+1} = \frac{y_{i+1} - y}{y_{i+1} - y_i}y_i + \frac{y - y_i}{y_{i+1} - y_i}y_{i+1} = y$

将标签转换为DFL的具体过程为：

- 将标签值xywh转换为ltrb

- 计算ltrb四个值，转换为DFL所需的积分形式（预测值 + 临近预测值）

$$

\begin{equation}
          y = \text{中心距某条边的距离} / \text{当前下采样倍数}
  \end{equation}

$$

 比如目标中心点距上边73 px，在最大下采样32倍的特征图中，计算其在DFL中的映射值$y = 73 / 32 = 2.3$。取整后得到的预测值为$y_i = 2$，临近值$y_{i+1} = 3$。根据映射值与预测值、临近预测值的接近程度，计算各自的权重为$y - y_i = 0.3$和$y_{i+1} - y = 0.7$

#### Quality Focal Loss
$$

\begin{equation}
    \mathbf{QFL}\left(\sigma\right) = -\left|y - \sigma\right|^\beta\left(\left(1 - y\right)\log\left(1 - \sigma\right) + y\log\left(\sigma\right)\right)
\end{equation}

$$

#### Generalized Focal Loss
模型去估计两个量$y_l$和$y_r$，（$y_l\textless y_r$）对应的$p_{y_l}$和$p_{y_r}$，（$p_{y_l}\geq 0, p_{y_r}\geq 0, p_{y_l} + p_{y_r} = 1, \hat{y} = y_lp_{y_l} + y_rp_{y_r}$）

$$

\begin{equation}
    \mathbf{GFL}\left(p_{y_l}, p_{y_r}\right) = -\left|y - \left(y_lp_{y_l} + y_rp_{y_r}\right)\right|^\beta\left(\left(y_r - y\right)\log\left(p_{y_l}\right) + \left(y - y_l\right)\log\left(p_{y_r}\right)\right)
\end{equation}

$$

### IoU及其变体

#### IOU

$$

\begin{equation}
    IoU = \frac{|A\cap B|}{|A\cup B|},IoU\in[0,1]
\end{equation}

$$

<figure id="IoU" data-latex-placement="H">
<img src="/images/target_detection/IOU.jpg" style="max-width:100%;height:auto;display:block;margin:0 auto;" />
<figcaption>相同的IoU对应不同的重叠方式。绿色方框为真实框；灰色区域为重叠区域；黑色方框为预测框</figcaption>
</figure>

> - 可以反映预测框和真框的相似度，满足尺度不变性【对尺度不敏感】；
>
> - 如果两个框没有相交【IoU=0】，影响梯度回传；
>
> - 无法精确的反映两个框的重合度大小图[2](#IoU)

#### GIoU
$$

\begin{equation}
    GIoU = IoU - \frac{|C-(A\cup B)|}{|C|},GIoU\in[-1, 1]
\end{equation}

$$

 其中，$|C|$为预测框和真实框的最小闭包区域面积；$|C-(A\cup B)|$为不属于两个框的区域。当且仅当真实框和预测框重合时，$GIoU = 1$；不存在交集时，$GIoU = -1$。

#### DIoU

$$

\begin{equation}
    DIou = Iou - \frac{\rho^2(b,b^{gt})}{c^2}
\end{equation}

$$

 其中，$b$，$b^{gt}$分别为预测框和真实框的中心点；$\rho$为欧式距离函数；$c$为预测框和真实框的最小闭包区域的对角线距离。

> - 和GIou一样，当预测框和真实框不存在重叠时，仍然可以正常梯度下降；
>
> - 可以直接衡量预测框和真实框的距离；
>
> - 当预测框和真实框为包含状态时，GIoU退化为IoU，DIoU仍**有可能**继续更新梯度；
>
> - DIoU也可以应用于NMS中。

#### CIoU
$$

\begin{align}
    CIoU &= IoU - \frac{\rho^2(b,b^{gt})}{c^2}-\alpha v\\
    v &= \frac{4}{\pi^2}\left(\arctan\frac{w^{gt}}{h^{gt}}-\arctan\frac{w}{h}\right)^2\\
    \alpha &=
\begin{cases}
    0, &if\quad IoU\textless 0.5\\
    \frac{v}{1-IoU+v}, &if\quad IoU\geq 0.5
\end{cases}
\end{align}

$$

> - 当预测框和真实框重叠较少时，即$IoU\textless 0.5$，CIoU退化为DIoU；
>
> - 当$IoU\geq 0.5$时，预测框和真实框的中心点存在重合的可能性，因此需要引入纵横比进一步调整预测框，依据于：
>
> - 当预测框和真实框的纵横比不一致时，$v$会比较大，可以继续保持loss的梯度。

#### EIoU

$$

\begin{equation}
    EIoU = IoU - \frac{\rho^2(b, b^{gt})}{c^2}-\frac{\rho^2(w, w^{gt})}{C_w^2} - \frac{\rho^2(h, h^{gt})}{C_h^2}
\end{equation}

$$

 其中，$C_w$和$C_h$分别为覆盖预测框和真实框的最小外接框的宽度和高度。

> - CIoU无法很好的度量预测框的宽和高具体的回归程度；
>
> - EIoU还结合了Focal loss【$L_{EIoU} = IoU^{\gamma}(1-EIoU)$】,**来降低与目标重叠较少的大量锚对回归框损失的贡献**。

```python
......

    if CIoU or DIoU or GIoU:
        cw = torch.max(b1_x2, b2_x2) - torch.min(b1_x1, b2_x1)  # 最小外接框的宽
        ch = torch.max(b1_y2, b2_y2) - torch.min(b1_y1, b2_y1)  # 最小外接框的高

### NMS合辑

**动机：**在执行目标检测任务时，可能对同一目标有多次检测，因此有必要"清理检测"，使得每个对象只得到一个检测。

#### NMS
非极大值抑制（Non-Maximum Suppressin，NMS）局部最大搜索\

::: algorithm
**输入：**候选框集合$\mathcal{B}$及其对应的置信度$\mathcal{S}$；阈值$N_t$【常用0.3-0.5】\
最终检测结果$\mathcal{D}\leftarrow\{\}$\
步骤一，从$\mathcal{B}$中选择最大score的检测框$m$；\
步骤二，将其从$\mathcal{B}$中移除并加入到最终检测结果$\mathcal{D}$中；\
步骤三，将$\mathcal{B}$中剩余检测框$b_i$与$m$的IOU大于$N_t$的框从$\mathcal{B}$中移除； **输出：**最终检测结果
:::

> - 在使用NMS之前需要预选框预处理【NMS耗时】；
>
> - 将相邻检测框的分数强制归零，当一个真实物体在重叠区域出现时，会致使该目标检测失败，降低平均检测率；
>
> - 阈值选取过于主观；
>
> - 只能CPU计算

#### 多类别NMS

> - [2.4.1](#NMS)的做法是把所有boxes放在一起做NMS，没有考虑类别【某一类的boxes不应该因为它与另一类最大得分boxes的iou值超过阈值而被筛掉】
>
> - 实现方式：为每个类别单独做NMS【给box坐标添加一个偏移量，偏移量由类别索引决定】

#### Soft-NMS

不像NMS一样粗暴的删除IOU大于阈值的检测框，Soft-NMS衰减分数。区别在于步骤三，前者：

$$

\begin{equation}
    s_i=
    \begin{cases}
        s_i, &iou\left(m,b_i\right)\textless N_t\\
        0, &iou\left(m,b_i\right)\geq N_t
    \end{cases}
\end{equation}

$$

后者有两种实现形式：

- 线性加权

$$

\begin{equation}
      s_i=
      \begin{cases}
          s_i, &iou\left(m,b_i\right)\textless N_t\\
          s_i\left(1-iou\left(m, b_i\right)\right), &iou\left(m,b_i\right)\geq N_t
      \end{cases}
  \end{equation}

$$

- 高斯加权

$$

\begin{equation}
      s_i = s_i e^{-\frac{iou\left(m,b_i\right)^2}{\sigma}}, \forall b_i\notin\mathcal{D}
  \end{equation}

$$

> - 不需要重新训练原有的模型，二值化时等价于NMS；
>
> - $\mathcal{B}$为空后，所有的候选框都还在，只是置信度发生了变化，还需要阈值处理一次。

#### Softer-NMS

**动机：**NMS仅使用了置信度得分，没法反映出候选框的定位精确度【分类置信度和定位置信度非正相关】

Softer-NMS引入了两个假设：

- 假设1：候选框的定位置信度（$x_e$）是高斯分布；

$$

\begin{equation}
      P_{\Theta}(x) = \frac{1}{\sqrt{2\pi\sigma^2}}e^{-\frac{(x-x_e)^2}{2\sigma^2}}
  \end{equation}

$$

- 假设2：真实框的定位置信度（$x_g$）是狄拉克分布，即标准方差为0的高斯分布极限

$$

\begin{equation}
      P_D(x)=\delta(x-x_g)
  \end{equation}

$$

用KL散度来衡量两个分布的相似度：

$$

\begin{align}
    L_{reg}
    &= \arg \min\limits_{\Theta} D_{KL}\left(P_D(x)||P_{\Theta}(x)\right)\\
    &=\int P_D(x)\log P_D(x)dx-\int P_D(x)\log P_{\Theta}dx \\
    &=-\log P_{\Theta}(x_g) + C_1\\
    &=\frac{(x_g-x_e)^2}{2\sigma^2} + \frac{\log\sigma^2}{2} + C_2
\end{align}

$$

 其中$C_1$，$C_2$均为常量。**根据链式法则**分别对$x_e$和$\sigma$求偏导：

$$

\begin{align}
    \frac{dL_{reg}}{dx_e} &= \frac{x_e-x_g}{\sigma^2}\\
    \frac{dL_{reg}}{d\sigma} &= -\frac{(x_e-x_g)^2}{\sigma^3}+\frac{1}{\sigma}
\end{align}

$$

设定$\alpha=\log(\sigma^2)$【动机和[4.3](#yolov3)节中回归框长宽缩放到对数空间一样】，此时

$$

\begin{equation}
    L_{reg} \propto \frac{e^{-\alpha}}{2}(x_g-x_e)^2+\frac{1}{2}\alpha
\end{equation}

$$

> - $\sigma$是网络预测的标准方差；
>
> - 狄拉克函数具体挑选性：$\int f(x)\delta(x-t_0)dx=f(t_0)$【见公式 ([\[狄拉克\]](#狄拉克))】；
>
> - 可以理解为所有$iou\left(m, b_i\right)\geq N_t$的候选框预测坐标的加权平均。

#### Fast NMS

每个类别独立执行的，基本流程为：

- 生成IoU矩阵：为当前类别的检测框计算IoU矩阵

- 初始化：将IoU矩阵的下三角和对角线设置为0

- 计算最大IoU：对IoU矩阵的每一列计算最大值，得到矩阵$K$

- 阈值过滤：根据阈值$t$决定哪些检测框被保留，哪些被抑制

- 输出结果：输出该类别的最终检测框列表

#### Weighted-Boxes-Fusion, WBF

> - 与单一模型相比，结合多个模型的预测会更好
>
> - NMS和soft-NMS只是简单地删除部分预测框
>
> - 比NMS慢3倍

具体的流程，可总结为：维护两个容器Clusters和Fusions【一个Fusion对应一簇Cluster】，详细步骤如下：\

::: algorithm
**输入：**候选框集合$\mathcal{B}$，按其对应的置信度$\mathcal{S}$降序排列；检测结果容器$\mathcal{L}$和融合容器$\mathcal{F}$，阈值$N_t$\
最终检测结果$\mathcal{D}\leftarrow\{\}$\
步骤一，按顺序从$\mathcal{B}$中取出一个框；\
步骤二，从$\mathcal{F}$中找到与之匹配的框，要求属于同一类别且mIoU $\textgreater N_t$。如果没有找到，则将其加到$\mathcal{L}$和$\mathcal{F}$的尾部；反之，则将其加到$\mathcal{L}$，加入位置为其在$\mathcal{F}$中匹配到的位置；\
步骤三，重新计算$\mathcal{F}$中的box坐标和置信度分数，融合$\mathcal{L}$中的所有box，融合公式为：

$$

\begin{align}
      \mathcal{S} & = \frac{\sum_{i=1}^T\mathcal{S}_i}{T} \\
      \mathcal{X}1,2 & = \frac{\sum_{i=1}^T\mathcal{S}_i*\mathcal{X}1,2_{i}}{\sum_{i=1}^T\mathcal{S}_i} \\
      \mathcal{Y}1,2 & = \frac{\sum_{i=1}^T\mathcal{S}_i*\mathcal{Y}1,2_{i}}{\sum_{i=1}^T\mathcal{S}_i}
\end{align}

$$

 步骤四，将$\mathcal{B}$中所有的框都处理完后，重新缩放$\mathcal{F}$中的置信度分数：

$$

\begin{equation}
      \mathcal{C} = \mathcal{C}*\frac{min\left(T, N\right)}{N}
\end{equation}

$$

 如果簇中的框数少，则意味着只有少数模型可以预测它，因此需要降低这种情况的置信度分数 **输出：**最终检测结果
:::

> **MaxIoUAssigner进行详细分析**
>
> 共4个步骤：
>
> - 初始化时候假设每个anchor的mask都是-1，表示都是忽略anchor
>
> - 将每个anchor和所有gt的iou的最大Iou小于neg_iou_thr的anchor的mask设置为0，表示是负样本（背景样本）
>
> - 对于每个anchor，计算其和所有gt的iou，选取最大的iou对应的gt位置，如果其最大iou大于等于pos_iou_thr，则设置该anchor的mask设置为1，表示该anchor负责预测该gt bbox,是高质量anchor
>
> - 3的设置可能会出现某些gt没有分配到对应的anchor（由于iou低于pos_iou_thr），故下一步对于每个gt还需要找出和最大iou的anchor位置，如果其iou大于min_pos_iou，将该anchor的mask设置为1，表示该anchor负责预测对应的gt。通过本步骤，可以**最大程度保证每个gt都有anchor负责预测，如果还是小于min_pos_iou，那就没办法了，只能当做忽略样本了**。从这一步可以看出，3和4有部分anchor重复分配了，即当某个gt和anchor的最大iou大于等于pos_iou_thr，那肯定大于min_pos_iou，此时3和4步骤分配的同一个anchor
>
> 在第4步中，每个gt最多只会和某一个anchor匹配，但是实际操作时候为了多增加一些正样本，通过参数gt_max_assign_all可以实现某个gt和多个anchor匹配场景。**通常第4步引入的都是低质量anchor，网络训练有时候还会带来噪声，可能还会起反作用**。
>
> 由于rcnn head预测值是rpn head的refine，故rcnn head面对的anchor（其实就是rpn输出的roi）和gt的iou会高于rpn head部分，anchor质量更高，故min_pos_iou阈值设置的比较高，由于pos_iou_thr和neg_iou_thr设置都是0.5，那么忽略区域那就是没有了，因为rcnn head面对的都是高质量样本，不应该还存在忽略区域。

    def get_random_data(self, annotation_line, input_shape, jitter=.3, hue=.1, sat=0.7, val=0.4, random=True):
        line   = annotation_line.split()
        image  = Image.open(line[0])
        image  = cvtColor(image)     # 读取图像并转换成RGB图像
        iw, ih = image.size          # 获取图像的宽高
        h, w   = input_shape         # 获取目标的宽高
        # 获取目标框信息
        box    = np.array([np.array(list(map(int, box.split(',')))) for box in line[1:]])
        if not random:
            scale      = min(w/iw, h/ih)
            nw         = int(iw*scale)
            nh         = int(ih*scale)
            dx         = (w-nw)//2
            dy         = (h-nh)//2
            image      = image.resize((nw,nh), Image.BICUBIC)
            new_image  = Image.new('RGB', (w,h), (128,128,128)) #  多余的部分加上灰条
            new_image.paste(image, (dx, dy))
            image_data = np.array(new_image, np.float32)

            #   调整真实框
            if len(box) > 0:
                np.random.shuffle(box)
                box[:, [0,2]] = box[:, [0,2]]*nw/iw + dx
                box[:, [1,3]] = box[:, [1,3]]*nh/ih + dy
                box[:, 0:2][box[:, 0:2]<0] = 0
                box[:, 2][box[:, 2]>w]     = w
                box[:, 3][box[:, 3]>h]     = h
                box_w = box[:, 2] - box[:, 0]
                box_h = box[:, 3] - box[:, 1]
                box   = box[np.logical_and(box_w>1, box_h>1)] # 丢弃无效框
            return image_data, box

**预测结果($t_x$，$t_y$，$t_w$，$t_h$)解码【中心点平移到蓝色点的过程】:**

网络输出获得边界框预测：

$$

\begin{align}
    b_x &= (\sigma\left(t_x\right) + c_x)/W\\
    b_y &= (\sigma\left(t_y\right) + c_y)/H\\
    b_w &= p_we^{tw}/W\\
    b_h &= p_he^{th}/H
\end{align}

$$

 其中，$(c_x, c_y)$为网格从顶左部的坐标；$p_w$，$p_h$分别是锚框的维度；$W$，$H$分别是特征图的维度。

在faster-RCNN中，$t_x$，$t_y$，$t_w$，$t_h$依次可以表示为：

$$

\begin{align}
    t_x &= \left(G_x-P_x\right)/P_w\\
    t_y &= \left(G_y-P_y\right)/P_h\\
    t_w &= \log\left(G_x/P_x\right)\\
    t_h &= \log\left(G_x/P_x\right)
\end{align}

$$

 其中，($P_x$，$P_y$)和($G_x$，$G_y$)分别为预设的anchor box和ground truth在特征图上的中心点坐标；($P_w$，$P_h$)和($G_w$，$G_h$)分别为预设的anchor box和ground truth在特征图上的宽和高【归一化变绝对尺度为相对尺度】。

> - 没有直接回归bounding box的长宽而是**尺度缩放到对数空间，去掉不等式约束【相对形变必须大于0】**
>
> - 当输入的Proposal与ground truth相差较小时，可以认为边框回归是一种**线性变换**\
>

$$

t_w = \log\left(G_w/P_w\right)=\log\left(1+\frac{G_w-P_w}{P_w}\right)=\frac{G_w-P_w}{P_w} \left(P_w-G_w \rightarrow 0\right)

$$
>
> - sigmoid压缩$t_x$，$t_y$到(0，1)，可以有效地确保目标中心位于预测的网格单元中

- 边界框损失：\

class Detect(nn.Module):
        # YOLOv3 Detect head for detection models
        stride = None  # strides computed during build
        dynamic = False  # force grid reconstruction
        export = False  # export mode

        def __init__(self, nc=80, anchors=(), ch=(), inplace=True):  # detection layer
            super().__init__()
            self.nc = nc  # number of classes
            self.no = nc + 5  # number of outputs per anchor
            self.nl = len(anchors)  # number of detection layers
            self.na = len(anchors[0]) // 2  # number of anchors
            self.grid = [torch.empty(0) for _ in range(self.nl)]  # init grid
            self.anchor_grid = [torch.empty(0) for _ in range(self.nl)]  # init anchor grid
            self.register_buffer("anchors", torch.tensor(anchors).float().view(self.nl, -1, 2))  # shape(nl,na,2)
            self.m = nn.ModuleList(nn.Conv2d(x, self.no * self.na, 1) for x in ch)  # output conv
            self.inplace = inplace  # use inplace ops (e.g. slice assignment)

        def forward(self, x):
            z = []  # inference output
            for i in range(self.nl):
                x[i] = self.m[i](x[i])  # conv
                bs, _, ny, nx = x[i].shape  # x(bs,255,20,20) to x(bs,3,20,20,85)
                x[i] = x[i].view(bs, self.na, self.no, ny, nx).permute(0, 1, 3, 4, 2).contiguous()

                if not self.training:  # inference
                    if self.dynamic or self.grid[i].shape[2:4] != x[i].shape[2:4]:
                        self.grid[i], self.anchor_grid[i] = self._make_grid(nx, ny, i)

                    xy, wh, conf = x[i].sigmoid().split((2, 2, self.nc + 1), 4)
                    xy = (xy * 2 + self.grid[i]) * self.stride[i]  # xy
                    wh = (wh * 2) ** 2 * self.anchor_grid[i]  # wh
                    y = torch.cat((xy, wh, conf), 4)
                    z.append(y.view(bs, self.na * nx * ny, self.no))

            return x if self.training else (torch.cat(z, 1),) if self.export else (torch.cat(z, 1), x)

        def _make_grid(self, nx=20, ny=20, i=0, torch_1_10=check_version(torch.__version__, "1.10.0")):
            d = self.anchors[i].device
            t = self.anchors[i].dtype
            shape = 1, self.na, ny, nx, 2  # grid shape
            y, x = torch.arange(ny, device=d, dtype=t), torch.arange(nx, device=d, dtype=t)
            yv, xv = torch.meshgrid(y, x, indexing="ij") if torch_1_10 else torch.meshgrid(y, x)  # torch>=0.7 compatibility
            grid = torch.stack((xv, yv), 2).expand(shape) - 0.5  # add grid offset, i.e. y = 2.0 * x - 0.5
            anchor_grid = (self.anchors[i] * self.stride[i]).view((1, self.na, 1, 1, 2)).expand(shape)
            return grid, anchor_grid
```

> **边框回归里面$wh$为什么要乘以2再平方**
>
> 主要是因为原始的框方程式存在缺陷，宽高虽然恒大于0，但不受限制，容易梯度不稳定，增加训练难度，因此使用$\left(2\sigma\left(t_w\right)\right)^2$，这样既能保证宽高恒大于0，也能对宽高加以限制，最大值为anchor框宽高的4倍

#### Feature pyramid network

#### 稀疏化训练

稀疏度训练有助于通道修剪，以删除不重要的通道。具体地，除检测头以外，YOLOV4中的每个卷积层后面都有一个BN层，用于加速收敛。

$$

\begin{equation}
    y = \gamma\times \frac{x-\overline{x}}{\sqrt{\sigma^2+\epsilon}+\beta}
\end{equation}

$$

 其中，$\overline{x}$和$\sigma^2$是小批量的输入特征的均值和方差，$\gamma$和$\beta$表示可训练的缩放因子和偏置。对缩放因子$\gamma$施加$L_1$正则化即可实现稀疏化训练：

$$

\begin{equation}
    loss = loss_{yolov4} + \alpha\sum_{\gamma}f(\gamma)
\end{equation}

$$

 其中，$f(\gamma)=|\gamma|$表示$L_1$范数。

  def labels_to_class_weights(labels, nc):
          if labels[0] is None: return torch.Tensor()
          labels = np.concatenate(labels, 0)
          classes = labels[:, 0].astype(int)
          weights = np.bincount(classes, minlength=nc)
          weights[weights == 0] = 1
          weights = 1 / weights # 标签越多，权重越少
          weights /= weights.sum() # 赋予每个类别的权重为该类别的目标框数

#### 推理阶段
```python
def __yolov5_decode(self,
                        feats: List[ndarray],
                        conf_thres: float,
                        num_labels: int = 80,
                        **kwargs):
        anchors: Union[List, Tuple] = kwargs.get(
            'anchors',
            [[(10, 13), (16, 30),
              (33, 23)], [(30, 61), (62, 45),
                          (59, 119)], [(116, 90), (156, 198), (373, 326)]])
        for i, feat in enumerate(feats):
            stride = 8 << i
            feat_h, feat_w, _ = feat.shape
            anchor = anchors[i]
            feat = sigmoid(feat)
            feat = feat.reshape((feat_h, feat_w, len(anchor), -1))
            box_feat, conf_feat, score_feat = np.split(feat, [4, 5], -1)

            hIdx, wIdx, aIdx, _ = np.where(conf_feat > conf_thres)

            num_proposal = hIdx.size
            if not num_proposal:
                continue

            score_feat = score_feat[hIdx, wIdx, aIdx] * conf_feat[hIdx, wIdx, aIdx]
            boxes = box_feat[hIdx, wIdx, aIdx]
            labels = score_feat.argmax(-1)
            scores = score_feat.max(-1)

            indices = np.where(scores > conf_thres)[0]
            if len(indices) == 0:
                continue

            for idx in indices:
                a_w, a_h = anchor[aIdx[idx]]
                x, y, w, h = boxes[idx]
                x = (x * 2.0 - 0.5 + wIdx[idx]) * stride
                y = (y * 2.0 - 0.5 + hIdx[idx]) * stride
                w = (w * 2.0)**2 * a_w
                h = (h * 2.0)**2 * a_h

                x0 = x - w / 2
                y0 = y - h / 2

                self.scores_pro.append(float(scores[idx]))
                self.boxes_pro.append(
                    np.array([x0, y0, w, h], dtype=np.float32))
                self.labels_pro.append(int(labels[idx]))
```

> **和yolov3相比，yolov5的边框回归方式有什么不同之处**
>
> yolov5先对$\left(t_x, t_y\right)$sigmoid处理后，再对其两倍计算后减去0.5。这与yolov5正样本的定义有关。yolov5和yolov3/v4有两点不同：
>
> - 匹配规则：从IOU匹配变成shape匹配，先计算gt与9个anchor的长宽比，如果长宽比小于设定阈值，说明该gt和对应的anchor匹配，一个gt可能与几个anchor均能匹配上，因为同之前yolo一样，yolov5有三层网络，9个anchor, 从小到大，每3个anchor对应一层网络，所以一个gt可能在不同的网络层上做预测训练，**大大增加了正样本的数量**，当然也会出现gt与所有anchor都匹配不上的情况，这样gt就会被当成背景，不参与训练，说明anchor框尺寸设计的不好
>
> - 筛选框：gt框与anchor框匹配后，得到anchor框对应的网络层的grid，看gt中心点落在哪个grid上，不仅取该grid中和gt匹配的anchor作为正样本，还取相邻的的两个grid中的anchor为正样本，**增大正样本数量，避免正负样本失衡**

#### Strong augmentation

在网络的输入端，Yolox主要采用了Mosaic、Mixup两种数据增强方法。而采用了这两种数据增强，直接将Yolov3 baseline，提升了2.4个百分点。

- Mosaic增强的方式，是U版YOLOv3引入的一种非常有效的增强策略。而且在Yolov4、Yolov5算法中，也得到了广泛的应用。通过随机缩放、随机裁剪、随机排布的方式进行拼接，对于小目标的检测效果提升，还是很不错的。

- MixUp是在Mosaic基础上，增加的一种额外的增强策略。主要来源于2017年，顶会ICLR的一篇论文《mixup: Beyond Empirical Risk Minimization》。当时主要应用在图像分类任务中，可以在几乎无额外计算开销的情况下，稳定提升1个百分点的分类精度。

  > **需要注意两点：**
  >
  > - 在训练的最后15个epoch，这两个数据增强会被关闭掉。而在此之前，Mosaic和Mixup数据增强，都是打开的；
  >
  > - 由于采取了更强的数据增强方式，作者发现，ImageNet预训练将毫无意义，因此，所有的模型，均是从头开始训练的

> **无节制的数据增强是否真的更好呢？**
>
> - Mosaic和Mixup混合策略：对于轻量级网络，比如Yolox-nano，在Mosaic基础上，增加Mixup，AP值会不增反降；而对于深一些的网络，比如Yolox-L，在Mosaic基础上，增加Mixup，AP值会有所上升。因此不同的网络结构，采用数据增强的策略也不同，比如Yolox-s、Yolox-m，或者Yolov4、Yolov5系列，都可以使用不同的数据增强策略进行尝试
>
> - Scale增强策略：在Mosaic数据增强中，random_perspective函数，生成仿射变换矩阵时，对于图片的缩放系数，会生成一个随机值。对于Yolox-l来说，随机范围scale建议设置在\[0.1，2\]之间，而对于轻量级模型，比如YoloNano时，随机范围scale建议设置在\[0.5，1.5\]之间，弱化Mosaic增广的性能。

#### Prediction层

在输出层中，主要从四个方面进行讲解：Decoupled Head、Anchor Free、标签分配、Loss计算。

- Decoupled Head：目前在很多一阶段网络中都有类似应用，比如RetinaNet、FCOS等。在Yolox中，作者增加了三个Decoupled Head，俗称"解耦头"。

  <figure id="Decoupled_Head" data-latex-placement="H">
  <img src="/images/target_detection/Decoupled_Head.png" style="max-width:100%;height:auto;display:block;margin:0 auto;" />
  <figcaption>Decoupled_Head结构图</figcaption>
  </figure>

  > **为什么使用Decoupled Head？**
  >
  > 作者将输出端改进为End-to-end的方式（即无NMS的形式）。发现，改进完之后的AP值下降了4.2个百分点（38.5-\>34.3）。而将将End-to-End中的Yolo Head，修改为Decoupled Head的方式后，AP值从34.3增加到了38.8。然后作者又将Yolov3 baseline 中Yolo Head，也修改为Decoupled Head。发现AP值，从38.5增加到39.6，并且训练收敛的速度也加快了。但是将检测头解耦，会增加运算的复杂度。

- Anchor free：目前行业内，主要有Anchor Based和Anchor Free两种方式。在Yolov3、Yolov4、Yolov5中，通常都是采用Anchor Based的方式，来提取目标框，进而和标注的groundtruth进行比对，判断两者的差距。

> **Anchor Based和Anchor Free的区别**
>
> - Anchor Based：设置Anchor规则，将预测框和标注框进行关联。基于每个单元格，都有三个不同尺寸大小的锚框。以输入图像大小$416\times 416$为例。网络最后的三个特征图大小为$13\times 13$，$26\times 26$，$52\times 52$。当采用COCO数据集，即有80个类别时。基于每个锚框，都有x、y、w、h、obj（前景背景）、class（80个类别），共85个参数。因此会产生$3\times\left(13\times 13 + 26\times 26 + 52\times 52\right)\times 85 = 904995$个预测结果。如果将输入从$416\times 416$，变为$640\times 640$，最后的三个特征图大小为$20\times 20$，$40\times 40$，$80\times 80$。则会产生$3\times\left(20\times 20 + 40\times 40 + 80\times 80\right)\times 85 = 2142000$个预测结果
>
> - Anchor Free：以输入图像大小$640\times 640$为例，[9](#Decoupled_Head)中黄色的$85\times 8400$，不是类似于Yolov3中的Feature Map，而是特征向量。比基于Anchor Based的方式，少了2/3的参数量。

> **Anchor Based的局限性！**
>
> - Anchor的设置需要手动设计
>
> - Anchor的匹配机制使得极端尺度被匹配到的频率较低
>
> - Anchor的庞大数量使得存在严重的不平衡问题
>
> - 为了兼顾多尺度下的预测能力，推理得到的预测框也相对较多，nms耗时较大

> **Anchor Free就是真的没有锚框吗？**
>
> 其实并不然，YOLOX-Darknet53只是巧妙的将前面Backbone中，下采样的大小信息引入进来。图[8](#YOLOX)最上面的分支，下采样了5次（$2^5 = 32$），输出大小为$20\times 20\times 85$。也就是说**最后8400个预测框中，其中有400个框，所对应锚框的大小，为$32\times 32$**。同样的原理，中间的分支，最后有1600个预测框，所对应锚框的大小，为$16\times 16$。最下面的分支，最后有6400个预测框，所对应锚框的大小，为$8\times 8$。当有了8400个预测框的信息，每张图片也有标注的目标框的信息。这时需要做的，就是将8400个锚框，和图片上所有的目标框进行关联，挑选出正样本。而相应的，正样本锚框所对应的位置，就可以将正样本预测框，挑选出来。这里采用的关联方式，是**标签分配**。
>
> 简单地说，Anchor Base指的是使用聚类方法生成多种宽高比的锚框，模型在预测Bounding Box时其实是在预测Bound Box的中心点和锚框中心点的偏移以及宽高比例。Anchor Free中，模型是直接预测Bound Box的宽高值。

> **如何实现标签分配？**
>
> 需要明确一点，预测框只有少部分是正样本，绝大多数是负样本。那么如何挑选正样本呢？这里就涉及到两个关键点：初步筛选和SimOTA。
>
> - 初步筛选：初步筛选的方式主要有两种：根据中心点来判断、根据目标框来判断；
>
>   - 根据中心点来判断：寻找anchor_box中心点，落在groundtruth_boxes矩形范围的所有anchors
>
>   - 根据目标框来判断：以groundtruth中心点为基准，设置边长为5的正方形，挑选在正方形内的所有锚框。
>
> - 引入SimOTA，实现精细化筛选：整个筛选流程主要分为5个阶段：
>
>   - 初筛正样本：初筛出的1000个正样本锚框的位置
>
>   - 计算anchor与gt的iou
>
>   - 在候选区域内计算cost。开始$Lcls: Lreg = 1: 3$，而最终计算loss时，$Lcls: Lreg = 1: 5$
>
>     **猜测可能是在寻找正负样本时，如果一个anchor已经能很好的区分前景和背景了，那么即使reg预测不准，也可以作为正样本，所以相比较loss计算，在cost计算时，Lcls给予了更大的权重。而reg可以通过不断地训练逐步优化**
>
>   - 获取当前gt的iou前10（**在5-15之间取值，结果的影响差距较小**）的样本；并将这top10样本的iou求和取整，作为当前gt需要分配到的正样本数dynamic_k（最小取1，由于前期模型预测不准，导致iou基本比较小，所以观测到前期dynamic_k大多为1，**会不会导致训练速度变缓的情况？**）
>
>   - 舍去全局优化求解过程，只为每个gt取cost排名最小的前dynamic_k个anchor作为正样本，其余为负样本
>
>   - 人工去掉同一个样本被分配到多个gt的正样本的情况

**注：**SimOTA与OTA相比在最后两步做了简化，因此比OTA的运算速度更快，训练时间更短，不需要额外的优化参数步骤，同时保证了精度在绝大多数数据集下几乎没有影响。

#### ELAN
主干网络大量堆叠ELAN结构，该结构会将卷积层的输入与输出concat，从而产生更多的梯度流，为了防止因为某一层卷积导致特征丢失。

```python
class MultiConcatBlock(nn.Module):
        def __init__(self, c1: int, c2: int, c3: int, n: int = 4, e: int = 1, ids=None):
            super(MultiConcatBlock, self).__init__()
            if ids is None:
                ids = [0]
            c_ = int(c2 * e)

            self.ids = ids
            self.cv1 = Conv(c1, c_, 1, 1)
            self.cv2 = Conv(c1, c_, 1, 1)
            self.cv3 = nn.ModuleList([Conv(c_ if i == 0 else c2, c2, 3, 1) for i in range(n)])
            self.cv4 = Conv(c_ * 2 + c2 * (len(ids) - 2), c3, 1, 1)

        def forward(self, x: torch.Tensor) -> torch.Tensor:
            x_1 = self.cv1(x)
            x_2 = self.cv2(x)

            x_all = [x_1, x_2]
            for i in range(len(self.cv3)):
                x_2 = self.cv3[i](x_2)
                x_all.append(x_2)
            out = self.cv4(torch.cat([x_all[_id] for _id in self.ids], dim=1))
            return out
```

#### TransitionBlock&MP

主干网络的下采样层使用的是TransitionBlock和MP结构，该结构的特点是同时使用池化层（步长为2）和卷积层（步长为2），实现特征层的2倍降维。

```python
class MP(nn.Module):
        def __init__(self, k: int = 2):
            super(MP, self).__init__()
            self.m = nn.MaxPool2d(kernel_size=k, stride=k)

        def forward(self, x: torch.Tensor) -> torch.Tensor:
            return self.m(x)

    class TransitionBlock(nn.Module):
        def __init__(self, c1: int, c2: int):
            super(TransitionBlock, self).__init__()
            self.cv1 = Conv(c1, c2, 1, 1)
            self.cv2 = Conv(c1, c2, 1, 1)
            self.cv3 = Conv(c2, c2, 3, 2)
            self.mp = MP()

        def forward(self, x: torch.Tensor) -> torch.Tensor:
            x_1 = self.mp(x)
            x_1 = self.cv1(x_1)

            x_2 = self.cv2(x)
            x_2 = self.cv3(x_2)

            return torch.cat([x_2, x_1], 1)
```

#### Neck

Neck部分使用了RepConv结构，与yolov6[4.7](#YOLOV6)中的结构一样，预测阶段会将多个卷积核融合成一个$3\times 3$的卷积，从而提高推理的速度。延续yolov5使用路径聚合网络[4.4.4](#PAN)，实现上层、底层特征融合。

#### Head

yolov7的head与yolov5是一样的，预测的公式也是一样的。预测的是grid的中心点，因此再图像坐标系下允许偏移量的范围为-0.5到1.5。

#### 正负样本筛选

yolov5的正样本是静态选择，yolov7已经升级为动态选择。会先使用yolov5的方法选择候选样本，然后再此基础之上使用SimOTA算法[\[SimOTA\]](#SimOTA)进一步筛选正样本。SimOTA会根据现阶段模型训练程度选择正样本数目，具体表现为依据iou确定正样本数目，依据3 \* iou_loss和cls_loss作为最终筛选依据。这里iou_loss的系数与cls_loss的系数之比为3:1，目的是让该阶段更多关注与候选的anchor是不是目标，而不需要过分关注具体的类别。yolov5候选正样本 (最多27个)。

- 对每一个GT框，分别计算与anchor的宽与宽的比值、高与高的比值

- 取比值在1/4-4之间的作为候选项; 取比值最接近的当做候选项

- 分别计算ground_truth中心点与候选anchor左上角的偏移量，确定是在第几象限，进而进一步确定扩展出来的两个anchor是在上，下，左，右哪一个方向;

- 对于同一个anchor匹配多个ground_truth情况，取最大iou值的ground_truth;

#### TaskAlignedAssigner
现代目标检测器大部分都会在正负样本分配策略上面做文章，典型的如YOLOX的 simOTA、TOOD的TaskAlignedAssigner和RTMDet的DynamicSoftLabelAssigner，这类Assigner大都是动态分配策略

TaskAlignedAssigner的匹配策略简单总结为：**根据分类与回归的分数加权的分数选择正样本**。

$$

\begin{equation}
    t = s^\alpha \times u^\beta
\end{equation}

$$

 其中，$s$是标注类别对应的预测分值，$u$是预测框和gt框的iou，两种相乘可以衡量对齐程度

- 对于每一个GT，对所有的预测框基于GT类别对应分类分数，预测框与GT的IoU的加权得到一个关联分类以及回归的对齐分数alignment_metrics

- 对于每一个GT，直接基于alignment_metrics对齐分数选取topK大的作为正样本

> **样本匹配策略总结**
>
> - 静态策略：基于经验得出，在训练开始之前就确定了，可以根据数据集的特点进行调整。为了让正样本分配更合理，提出了**正样本增样**。比如：
>
>   - 跨分支采样：在三种尺寸的特征图上都对GT匹配
>
>   - 跨grid采样：若GT落在某网格内，将此网格左、上、右、下4个领域内离GT中心较近的两个网格作为正样本
>
>   - 跨anchor采样：根据宽高比匹配正样本。如果anchor和GT的宽高比小于阈值，就匹配成功。可理解为GT满足anchor宽和高都在 x 0.25 和x4.0倍之间就算匹配成功
>
>   **注：**在v5中一个目标最多可有9-27个正样本
>
> - 动态匹配[4.9.3](#TAL)：可根据训练损失或其他指标来调整，可以更好的适应不同的数据集和模型

#### Loss计算

Loss不再有之前的objectness分支，只有解耦的分类和回归分支

- 分类分支：依然采用BCE Loss

- 回归分支：需要和DFL[2.2.2](#DFL)中提出的积分形式表示法绑定，同时还使用了CIoU[2.3.4](#CIoU)

### YOLOV9

**大清亡了！**

#### 创新点

解决深度神经网络中信息丢失所带来的挑战。信息瓶颈原理和可逆函数的创新使用是其设计的核心，可确保 YOLOv9 保持高效率和高精度。

#### 信息瓶颈原理

信息瓶颈原理揭示了深度学习中的一个基本挑战：**当数据通过网络的连续层时，信息丢失的可能性会增加**。这一现象在数学上表现为

$$

\begin{equation}
    I\left(X, X\right) \geq I\left(X, f_\theta\left(X\right)\right) \geq I\left(X, g_\phi\left(f_\theta\left(X\right)\right)\right)
\end{equation}

$$

 其中$I$表示互信息，而$f$和$g$表示带参数的变换函数$\theta$和$\phi$分别为YOLOv9通过实施可编程梯度信息（PGI）应对了这一挑战，PGI 有助于保留整个网络深度的重要数据，确保更可靠的梯度生成，从而提高模型的收敛性和性能。

#### 可逆函数

可逆函数的概念是 YOLOv9 设计的另一个基石。如果一个函数可以在不丢失任何信息的情况下被反转，那么这个函数就被认为是可逆的：

$$

\begin{equation}
    X = v_\zeta\left(r_\psi\left(X\right)\right)
\end{equation}

$$

 与$\psi$和$\zeta$分别作为可逆函数及其反函数的参数。这一特性对深度学习架构至关重要，因为它能让网络保留完整的信息流，从而更准确地更新模型参数。YOLOv9在其架构中加入了可逆函数，以降低信息退化的风险，尤其是在较深的层中，从而确保为物体检测任务保留关键数据。

#### 对轻型模型的影响

解决信息丢失问题对于轻量级模型尤为重要，因为轻量级模型通常参数化不足，在前馈过程中容易丢失大量信息。YOLOv9 的架构通过使用 PGI 和可逆函数，确保即使是精简的模型，也能保留并有效利用准确检测物体所需的基本信息。

#### 可编程梯度信息 (PGI)

PGI主要包括三个部分，

- 主分支：推理过程仅使用了主分支，因此不需要额外的推理成本；

- 多级辅助信息：旨在处理深度监督带来的误差累积问题，特别是多个预测分支的架构和轻量级模型。

### DETR

目标检测变换为一个集合预测的问题，**既不需要proposal，也不需要anchor，更不需要nms**

<figure data-latex-placement="H">
<img src="/images/target_detection/DETR.PNG" style="max-width:100%;height:auto;display:block;margin:0 auto;" />
</figure>

**encoder-decoder类似unet，前者负责提取特征抽象化，后者负责区分目标边缘**

```python
class DETR(nn.Module):
        def __init__(self, num_classes, hidden_dim, nheads,
        num_encoder_layers, num_decoder_layers):
            super().__init__()
            # We take only convolutional layers from ResNet-50 model
            self.backbone = nn.Sequential(*list(resnet50(pretrained=True).children())[:-2])
            self.conv = nn.Conv2d(2048, hidden_dim, 1)
            self.transformer = nn.Transformer(hidden_dim, nheads,
            num_encoder_layers, num_decoder_layers)
            self.linear_class = nn.Linear(hidden_dim, num_classes + 1)
            self.linear_bbox = nn.Linear(hidden_dim, 4)
            self.query_pos = nn.Parameter(torch.rand(100, hidden_dim))
            self.row_embed = nn.Parameter(torch.rand(50, hidden_dim // 2))
            self.col_embed = nn.Parameter(torch.rand(50, hidden_dim // 2))

        def forward(self, inputs):
            x = self.backbone(inputs)
            h = self.conv(x)
            H, W = h.shape[-2:]
            pos = torch.cat([
            self.col_embed[:W].unsqueeze(0).repeat(H, 1, 1),
            self.row_embed[:H].unsqueeze(1).repeat(1, W, 1), 28 ], dim=-1).flatten(0, 1).unsqueeze(1)
            h = self.transformer(pos + h.flatten(2).permute(2, 0, 1),
            self.query_pos.unsqueeze(1))
            return self.linear_class(h), self.linear_bbox(h).sigmoid()

    detr = DETR(num_classes=91, hidden_dim=256, nheads=8, num_encoder_layers=6, num_decoder_layers=6)
    detr.eval()
    inputs = torch.randn(1, 3, 800, 1200)
    logits, bboxes = detr(inputs)
```

Softer Teacher是一种端到端的半监督目标检测方法:

<figure id="softerteacher" data-latex-placement="H">
<img src="/images/target_detection/softer_teacher.png" style="max-width:100%;height:auto;display:block;margin:0 auto;" />
<figcaption>Caption</figcaption>

> 现有半监督学习方法的缺点：初始检测器的性能影响伪标签的质量，会影响最终的性能； 本文的两个创新点：
>
> - 未标注边界框的分类损失由teacher网络产生；
>
> - 框抖动方法【以框回归的方差作为定位可靠性度量】，用于选择可靠的伪框

损失函数由监督损失和无标注数据的无监督损失组成：

$$

\begin{equation}
    L = L_s + \alpha L_u
\end{equation}

$$

为了解决较高阈值导致的前景框被错分为背景类别的问题，Softer teacher通过对所有背景样本评估其真实背景的可靠性，让可靠性低的背景样本损失更低：

$$

\begin{equation}
    L_u^{cls} = \frac{1}{N_b^{fg}}\sum_{i=1}^{N_b^{fg}}l_{cls}\left(b_i^{fg}, G_{cls}\right)+\sum_{j=1}^{N_b^{bg}}w_jl_{cls}\left(b_j^{bg}, G_{cls}\right), \ w_j = \frac{r_j}{\sum_{k=1}^{N_b^{bg}}r_k}
\end{equation}

$$

一般地，通过teacher模型的预测得分就可以确定伪候选框的类别和坐标。事实上，前景得分区分正负样本与最后的回归准确度并无正向关系。因此本文通过度量回归预测的一致性来估计伪候选框的定位可靠性。具体地，将teacher模型预测的前景得分大于0.5的框多次抖动，然后继续送入teacher模型进行回归，计算抖动框的回归方差，方差越小，定位可靠性越高。

$$

\begin{equation}
    \overline\sigma_i = \frac{1}{4}\sum_{k=1}^4\hat{\sigma_k}, \ \hat{\sigma_k} = \frac{\sigma_k}{0.5\left(h(b_i)+w(b_i)\right)}
\end{equation}

$$
