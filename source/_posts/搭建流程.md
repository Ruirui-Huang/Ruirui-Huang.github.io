## 基本操作

### Hexo博客新建文章

详见：[指令/Hexo](https://hexo.io/zh-cn/docs/commands#new)

```bash
$ hexo new 我的第一篇博客
```

```bash
$ hexo new "My First Blog"
```

**注**：如果标题中包含空格，请使用引号括起来

### 生成页面

```bash
$ hexo generate / hexo g
```

### 启动预览

```bash
$ hexo sever / $ hexo s
```

访问：http://localhost:4000出现Hexo默认页面，本地博客安装成功！

### 部署预先生成的静态文件

```bash
$ hexo deploy / hexo d
```

即：进入网址<yourname.github.io>看到同样的效果</yourname.github.io>

**注**：进入网站可能会发现静态网站还未更新，等一会就好了，不需要重复操作！

### 删除文章

- hexo clean
- 删除文章
- hexo g

### 添加加载进度条

下载安装`progress module`

```bash
$ git clone https://github.com/theme-next/theme-next-pace source/lib/pace
```

在`/themes/next/_config.yml`中，设置如下：

```html
pace: true #是否开启进度条
pace_theme: pace-theme-center-atom #选择进度条样式
```

### 添加当前浏览进度

修改`themes/next/_config.yml`，把 `false` 改为 `true`：

```html
# Scroll percent label in b2t button.
scrollpercent: true
```

如果想放在侧边栏，搜索关键词`b2t`，把`false` 改为 `true`：

```html
# Back to top in sidebar (only for Pisces | Gemini).
b2t: false
# Scroll percent label in b2t button.
scrollpercent: true
```

参考：

### 预备备

1. 注册一个[GitHub](https://github.com/)账号
2. 安装[git](https://git-for-windows.github.io/)工具

### 开始

1. 进入Github首页，点击`New repository`新建一个项目
2. New
3. 填写仓库名称/勾选`Initialize this repository with a README`

### 提交

假设现在文件夹有一个文件`test.txt`需要上传

```bash
$ git add test.txt / git add .
$ git commit -m "说明"
$ git push #推送到默认分支
```

### git@ssh.github.com: Permission denied (publickey). spawn failed

**措施1**：

- 删除`.deploy_git`文件夹
- 输入`git config --global core.autocrlf false`
- hexo clean
- hexo generate
- hexo deploy

**措施2**：

chmod -R 777

显示新的错误信息：`Could not read from remote repository`

- 删除`.ssh`中的`id_rsa`和`id_rsa.pub`
- ssh-keygen -t rsa -C “https://github.com/Ruirui-Huang/Ruirui-Huang.github.io“
- 在GitHub中`Setting > SSH and GPG keys`中双击`New SSK key`，填入`id_rsa.pub`中的内容即可
- hexo deploy
