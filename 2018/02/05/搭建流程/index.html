简介：GitHub Pages ＆ Hexo

GitHub Pages 是什么？

GitHub Pages 是 GitHub 官方提供的免费静态站点托管服务，把公开仓库直接发布成网站，支持 HTTPS、免费、无停服风险——非常适合个人博客。

Hexo 是什么？

Hexo 是基于 Node.js 的静态博客框架，Markdown 写作，一条命令生成静态页面并部署到 GitHub Pages。部署产物（master 分支）与源文件（source 分支）分开管理是本博客的核心架构。

四、问题集合（全部实测）

GitHub 直连超时 / TLS 报错（schannel CRYPT_E_NO_REVOCATION_CHECK）

国内访问 GitHub 不稳定，clone/curl 常超时或报 TLS 错。解决：走镜像 https://ghfast.top/ 前缀加速下载。

hexo 8.x 命令无效（只显示 usage）/ 建议用 7.x

Hexo 8 存在兼容问题（console 命令空白）。解决：固定 7.3.0：

package.json 缺 hexo 字段导致生成 0 篇文章

缺 "hexo": { "version": "x.x.x" } 时 Hexo 认为站点未初始化，不加载任何插件（渲染器/生成器失效）。解决：补上该字段并重新 npm install。

主题报 template not found: _layout.njk

外部 hexo-renderer-nunjucks 破坏主题模板相对路径解析。解决：卸载，用 Hexo 7 内置 nunjucks：

代码高亮主题失效

highlight.js 11 已移除 tomorrow-night。解决：codeblock.theme.dark 用 atom-one-dark。

页面语言变德语（Suche/Erstellt）

语言代码不匹配导致回退默认语言。NexT 8 只有 zh-CN.yml。解决：language: zh-CN。

部署报 unable to auto-detect email address

.deploy_git 子仓库读不到仓库级身份。解决：配置全局 git 身份（见 1.1）。

Error: listen EADDRINUSE :::4000

部署被拒：! [rejected] master -> master (fetch first)

线上仓库有旧历史（如迁移场景），部署产物是整体替换，直接强制推送：

Windows tar 解压中文乱码

用 Python tarfile 解压（见 3.2），或 PowerShell 指定编码后处理。

Code 504: The app is archived（Valine 时代遗留，已过时）

老方案 Valine 依赖的 LeanCloud 2027-01-12 全面停服、数据销毁，本站已迁移 Utterances。如旧站页面残留 Valine 凭据（appId/appKey），仅作历史存档即可，不再使用。

五、LaTeX 学习笔记转博客正文（2026-09 实测）

场景：旧站部分文章以 <embed src="/pdf/xxx.pdf"> 嵌入 PDF 展示，不优雅且移动端体验差。本站在 Overleaf 有 LaTeX 源（ctexart + morelull 模板），可整体转为 Markdown 正文，公式用 KaTeX 渲染。

5.1 获取 Overleaf 源文件

  • 项目页可浏览器下载 zip：点击按钮后 wait_for_download（bu.download(zip链接) 直下无效、按钮被浮层遮挡时用 JS 按 [aria-label="Download .zip file"] 点击）。
  • zip 解压结构：main.tex + demo.tex + morelull.sty（自定义模板宏包）+ imgs&code/（图片）。

5.2 pandoc 转换（pypandoc-binary，pandoc 3.9）

  • 必须 --resource-path 指向图片目录，否则图片引用丢失；图片实际在 imgs&code/（不是 images/）。
  • pandoc 对 \includegraphics[scale=...] 输出无尺寸的 <img>；对 [width=...] 输出 <img style="width:90%">。都不是 markdown 图片语法。
  • 预处理：删除 \usepackage{morelull}（pandoc 解析该宏包会报错）；自定义环境 {提醒}/{问题}/{特点} → {quote}，否则内容丢失。
  • CRLF 坑：pandoc 输出用 \r\n，行首正则全部失效，clean() 开头必须 text.replace('\r\n', '\n')。
  • pandoc 会给标题加属性 # 标题 {#id}——hexo 会把它当模板注释解析报 FATAL（expected end of comment），转换后必须删掉 {#xxx}。

5.4 排版坑清单（全部实测）

问题 处理
正文 section 变 h1，6 个大标题抢文章标题层级 转换后所有标题降一级（#→##）
无尺寸大图溢出正文容器 所有 <img> 统一加 max-width:100%;height:auto;display:block;margin:0 auto
figure/figcaption 无样式 主题 custom_file_path.style: source/_data/styles.styl 加样式
块级公式不渲染 $$...$$ 必须独占段落（前后补空行）
\text{$y=1$} 嵌套 $ 去除 \text 内层 $；W_i_K 双下标按语义改 W_i^K
$^{\ref{xx}}$ 清理后残留孤立 $$ 先整删 $^{\ref{xx}}$ 再删 \ref{xx}
pandoc 对齐式表格不渲染为 table 转成 markdown 管道表格（或 -t markdown+pipe_tables）
表格内 $\geq$ 不渲染 直接替换为 Unicode ≥
hexo 增量生成不检测 md 变化（0 files） 转换后务必 hexo clean && hexo g
